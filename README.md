# 🎓 부산대학교 학생회 학과별 설문 데이터 분석 대시보드

본 프로젝트는 부산대학교 학생회 차원에서 재학생들의 설문조사 CSV 데이터를 업로드하여 학과별 생활 패턴 및 의견을 인터랙티브하게 시각화·분석할 수 있도록 제작된 **Streamlit 웹 애플리케이션**입니다.

---

## 📌 주요 기능

1. **CSV 데이터 업로드 및 미리보기**
   - 사용자 정의 설문 CSV 파일을 업로드하여 원본 데이터를 상위 5행 미리보기로 확인
   - 필수 컬럼(`학과`, `만족도`, `통학시간`, `공부시간`, `스마트폰`, `한줄의견`) 무결성 검증

2. **자동 결측치 및 이상치 정제**
   - 결측치 및 음수 등 비정상 데이터를 필터링하고 제외된 총 건수를 사용자에게 안내

3. **학과별 동적 필터링**
   - 선택한 학과에 따라 평균 만족도(10.0점 만점 기준) 및 모든 시각화 차트가 즉시 연동

4. **시각화 대시보드**
   - **일일 생활시간 원그래프**: 통학시간(분 단위)을 시간 단위로 자동 환산하여 공부시간, 스마트폰 사용시간과의 비율을 정확히 표시
   - **한줄의견 워드클라우드**: KoNLPy(Okt) 기반 한글 명사 추출 및 시각화
   - **최다 언급 단어 Top 10 가로 막대그래프**: 빈도수 및 단위 표기
   - **감성 분석 막대그래프**: 형용사·동사 어간 및 명사를 포괄하는 사전 매칭을 통해 긍정/부정 단어 등장 횟수 비교

---

## 🛠 필수 요구사항 (Prerequisites)

- Python 3.9 이상
- **Java (JDK 8 이상)**: KoNLPy 형태소 분석기 구동을 위해 필요합니다.
- **NanumGothic 폰트**: 한글 깨짐 방지를 위해 `NanumGothic.ttf` 파일이 프로젝트 루트 경로에 위치해야 합니다.

---

## 🚀 설치 및 실행 방법

### 1. 저장소 복제 (Clone)
```bash
git clone https://github.com/your-username/pnu-student-survey-analysis.git
cd pnu-student-survey-analysis
```

### 2. 가상환경 생성 및 패키지 설치
```bash
# 가상환경 생성 (선택 사항)
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 의존성 패키지 설치
pip install -r requirements.txt
```

### 3. 한글 폰트 준비
- 프로젝트 루트 디렉토리에 `NanumGothic.ttf` 파일을 배치합니다.

### 4. 애플리케이션 실행
```bash
streamlit run app.py
```

## 📂 CSV 입력 데이터 형식 가이드

업로드하는 CSV 파일은 아래 6개 컬럼을 반드시 포함해야 합니다.

| 컬럼명 | 데이터 타입 | 설명 / 단위 |
| :--- | :--- | :--- |
| `학과` | 문자열 (String) | 학생 소속 학과명 |
| `만족도` | 수치형 (Numeric) | 학교/학과 만족도 (0 ~ 10점 만점) |
| `통학시간` | 수치형 (Numeric) | 하루 편도 또는 왕복 통학 소요 시간 (**분** 단위) |
| `공부시간` | 수치형 (Numeric) | 하루 자율 공부 시간 (**시간** 단위) |
| `스마트폰` | 수치형 (Numeric) | 하루 스마트폰 사용 시간 (**시간** 단위) |
| `한줄의견` | 문자열 (String) | 학생들의 자유 서술형 피드백 |
